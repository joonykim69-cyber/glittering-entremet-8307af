# test/ — 회귀 안전망

```bash
npm test                 # 전부 실행
npm test quota           # 파일명에 'quota'가 들어간 것만
node test/quota.test.js  # 파일 하나만 직접
```

의존성 0(Node 내장만), 네트워크 호출 0, 전체 6초 이내. `test/*.test.js`를 각각 **별도
프로세스**로 돌린다 — 이 테스트들은 `global.__FAKE_STORE__`/`global.fetch`를 갈아끼우므로
한 프로세스에서 이어 돌리면 앞 테스트의 전역이 뒤로 새어 들어가 없는 통과를 만든다.

## 이 테스트들이 지키는 것

프레임워크 관례가 아니라 **헌장 규율**을 지킨다. "동작하는가"보다 "우리가 하지 않기로 한 일을
정말 안 하는가"가 핵심이다.

| 파일 | 지키는 규율 |
|---|---|
| `predict-seal` | 봉인 **전수**(페이지 상한으로 유실 없음)·**불변**(재봉인 0)·**공식 불변**(mid/lo/hi 수치 대조)·상한 시 마감 임박 순 |
| `score-daily` | 전수 채점·이중 집계 0·레벨별 관측 |
| `mkt-seal` | 시세 밴드 봉인 불변(시세가 급변해도 덮어쓰지 않음)·채점이 봉인값 미변경·재실행 이중집계 0 |
| `mkt-backtest` | GR11(as-of 이후 거래 미참조)·표본 부족 시 미산출 |
| `collect-rtms` | 커서 재개·빈 셀 미저장·재실행 no-op |
| `collect-history` | 증분 고정 키(블롭 무한 누적 방지)·재실행 누적 0 |
| `quota` | 대량 수집기가 사용자 화면 몫을 침범하지 않음·**반쪽 창을 남기지 않음**(커서 미전진) |
| `alerts` | 같은 물건·단계 재발송 0·키 없으면 보낸 척 안 함·수신거부 시 이메일 삭제·불필요 필드 미저장 |
| `hwp` | HWP/HWPX 추출, 암호 문서는 정직하게 실패 (fixture는 제3자 구현 생성 — `fixtures/README.md`) |
| `curation` | 주목 점수는 근거 태그로 분해·근거 없으면 null |
| `gbtree` / `backtest-v08` | 분위수 GBDT 수치 정확도·GR11(예측 피처에 win 없음) |
| `sim-live` | GR11 — 예측 함수에 미래(win)를 넣어도 무시함을 실증 |
| `market-est` / `rtms-svc` | 실응답 형태 fixture로 파싱(과거 `{item:"<원시XML>"}` 버그 재발 방지) |
| `news-dedup` | 재게재 보도 제거·다른 회차 보존 |
| `mdlite` / `faildiag` | 임의 HTML 주입 차단·유찰 신호 판정 |
| `manifesto` | **헌장이 사실인가** — Appendix A/B 인벤토리·스키마가 실제 파일·크론과 일치, GR12 존재, 낡은 수치 미포함 |

## `manifesto.test.js`가 일부러 깨지는 경우

함수·lib·테스트·페이지를 **추가하면 이 테스트가 실패합니다.** 버그가 아니라 의도된
트립와이어입니다 — 헌장 Appendix A(인벤토리)는 사실 기술이므로, 코드가 늘었는데 문서가
그대로면 헌장이 거짓말을 하게 됩니다. 실패 메시지에 실제 값이 찍히니 그 값으로 헌장을
고치면 됩니다.

## 아직 덮지 못한 것 (정직하게)

- **클라이언트 HTML 페이지** — 렌더 검증은 브라우저(Playwright)가 필요해 이 스위트에 없다.
  페이지 변경은 여전히 인라인 스크립트 문법 검사 + 수동 확인에 의존한다.
- **실 외부 API** — 이 개발환경은 프로덕션 도메인으로 나가는 egress가 막혀 있어 라이브 호출을
  검증할 수 없다. fixture는 **실제 응답 구조를 그대로 재현한 것**을 쓰되(내 가정대로 만든
  목킹이 rtms-svc 파서 버그를 놓친 전례가 있다), 라이브 확인은 배포 후 창업자 몫으로 남는다.
- `agents.js`·`doc-extract.js`의 LLM 경로 — 생성 품질은 fixture로 판정할 수 없다.
  프롬프트 규율(면책 부착·"기재 없음" 강제)만 코드 리뷰로 확인한다.
